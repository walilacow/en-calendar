🛠 聲播日曆 後台管理手冊 2026-09 版

本手冊說明後台（test/admin.html）的登入方式、主播收禮統計、任務範本管理、廳房設定，以及最高管理者專用的帳號與角色設定頁。後台與主播 App 共用同一個 Firebase 專案，資料即時同步。

〇、登入後台

  1. 開啟後台網址（…/test/admin.html），先輸入通行密碼（由管理員提供）
  2. 密碼正確後才會出現 Google 登入 畫面，用 Google 帳號登入
  3. 登入成功即進入後台；通行密碼與 Google 登入狀態都會記住，下次開啟不用重打
Google 一鍵登入按鈕若無法顯示（部分瀏覽器擋第三方 cookie），可改按「🔁 改用傳統登入（跳轉 Safari）」，登入完成會自動跳回。
通行密碼只是「擋住路人」的門檻，並不是真正的資料權限控管——懂技術的人仍可能繞過。真正決定誰能讀寫資料的是 Firestore 安全規則，請勿把密碼當成唯一防線。

一、頁面結構

後台分成兩個分頁，用最上方的兩個按鈕切換：

分頁用途
📊 收禮統計看每位主播的業績、任務、開播時數與每日明細；指派廳房；刪除主播
📋 任務範本依廳房建立日／週／月／自訂任務範本，主播在 App 一鍵同步

二、收禮統計

期間切換

  • 上方「本週／本月」切換統計期間
  • 下方選單可回看本週＋前 3 週或本月＋前 3 個月，切換後所有數字與每日明細都會重算

主播列表（收合摘要）

  • 每位主播預設只顯示一行摘要：暱稱、廳房、業績分數、任務分數、任務＋時數總分、開播時數
  • 點摘要列展開完整明細；再點一次收合。展開狀態在資料即時更新時會保留
  • 摘要列右側的廳房下拉與🗑 刪除鈕點了不會展開／收合

展開後的明細

  • 三個統計框：業績分數、任務分數、任務＋時數總分
  • 📻 開播時數 → 時數分數（每滿 1 小時 +5 分，只計「完成開播」有打勾的時段）
  • 每日三條：橘＝業績、紫＝任務、藍＝時數
  • 點紫色任務分數條或旁邊的數字，會跳出當天完成的任務／禮物明細（✅ 已完成、⬜ 未完成、完成數／目標、分數）
明細裡的週任務、月任務只會出現在「該週／該月新達成分數」的那一天，同一份週／月任務不會在其他天重複出現，避免重複計算。
主播若在 App 設定裡關閉「啟用業績分數」，後台該主播的業績統計框、橘色業績條與圖例會一併隱藏。

分數怎麼算

  • 每日任務（普通／簡／加碼）：直接依當天任務清單即時計算，主播事後回頭補登或修改過去某天的任務，後台數字會跟著更新
  • 週／月任務：依每日快照差額，把新增的分數歸到「實際達標的那一天」
  • 業績分數：依主播自己的「每日分界」設定（00:00 或 08:00）歸日

指派廳房

  • 摘要列右側的廳房下拉，選好即自動存檔（框線閃綠色表示已儲存）
  • 廳房決定主播在 App 按「同步範本任務」時抓哪一份範本
  • 未指派的主播視為「未知」廳

刪除主播

  1. 點摘要列右側的 🗑
  2. 會連續確認兩次，兩次都按確定才會真的刪除
刪除會清掉該主播在雲端的全部資料（任務、分數、聽眾資料卡、設定），無法復原。該主播下次登入 App 會被視為全新使用者，需要重新輸入暱稱等資料，本機殘留的舊資料也不會被拿來覆蓋回雲端。

三、任務範本

在這裡建立的任務，主播在 App 日面板點「☁️ 同步範本任務」就能一次帶入，不用自己手動輸入。

選擇廳房

  • 「🏠 編輯廳房」下拉選擇要編輯哪個廳房的範本——每個廳房各存一份範本，互不影響
  • 主播同步時只會抓自己被指派廳房的範本
新增廳房請到最高管理者頁面（見第七節）；新增後，後台重新整理即可在廳房下拉看到新廳房。

日／週／月／自訂 分頁

  • 四個分頁各自獨立一份清單
  • 自訂分頁的任務，只有主播在 App 當下開著某個自訂區間時才會一併帶入

新增任務

  • 輸入任務項目、數量（目標個數）、分數、選圖示 →「新增」
  • ✨簡（5 分）／🔥加碼（100 分）勾選只在「日任務」分頁出現；週／月／自訂任務一律是普通任務
  • 同名任務不能重複新增

編輯任務

  1. 點任務名稱或右側 ✏️，該筆會亮紫框，資料載入上方表單
  2. 修改後按「💾 儲存」；按「取消編輯」或再點同一筆可取消

拖曳排序與刪除

  • 按住每筆左側的 ☰ 上下拖曳可調整順序（手機觸控也可以）
  • 點右側 ✕ 刪除該筆範本任務

複製任務清單到剪貼簿

清單最下方的「📋 複製任務清單到剪貼簿」會把目前廳房的日／週／月範本整理成文字，方便貼到群組公告，格式如下：

日任務(09/16)
任務A * 80
任務B（加碼） * 5

週任務(9/13~9/19)
任務C * 2

月任務(9月)
任務D * 3
  • 加碼任務名稱後會自動標註「（加碼）」
  • 週的日期範圍與月份會依「今天」自動帶入

四、範本與主播 App 的對應

  • 主播在 App 打開任一天的日面板，「複製前一天任務」上方有「☁️ 同步範本任務」按鈕
  • 同步會把該廳房範本的日／週／月（有開自訂區間時含自訂）任務帶入主播當下開啟的那一天
  • 同名任務不會重複加入，也不會蓋掉主播已收的進度；主播刪掉後再同步會補回來
  • 後台每次儲存範本都會更新版本號；主播 App 偵測到有新版本時，同步按鈕旁會出現紅色 NEW，同步一次後消失
主播反映「按了同步沒反應」時，通常是①該任務名稱已經在他的清單裡（不會重複新增），或②他被指派的廳房還沒建範本。先確認他的廳房，再看該廳房範本是否為空。

五、資料與權限

  • 後台與 App 共用同一個 Firebase 專案；主播資料在 Firestore users 集合，範本在 templates 集合（每個廳房一份文件，自訂廳房清單存在 templates/_meta，管理員／主播登記名單存在 templates/_admins）
  • 誰能讀寫哪些資料由 Firestore 安全規則決定（Firebase Console → Firestore → 規則），修改規則需到 Firebase Console 操作
  • Firebase 的 apiKey 等設定寫在前端程式碼裡是正常設計，並非機密；不要依賴隱藏原始碼來保護資料

六、部署更新

  1. 程式碼推上 GitHub main 分支後，GitHub Actions 會自動部署到 Firebase Hosting
  2. 若只改到 test/ 資料夾的檔案，需到 GitHub → Actions → 該 workflow → 「Run workflow」手動觸發
  3. 部署完成後若畫面還是舊的，請強制重新整理（清快取）

七、最高管理者頁面（帳號與角色設定）

另有一個獨立頁面 test/superadmin.html，用來登記管理員與主播的 Google 帳號、角色與所屬廳房，以及新增廳房。此頁不需要後台通行密碼，但只有最高管理者的 Google 帳號登入後才會顯示內容，其他帳號登入會看到「沒有權限」。

清單內容

  • 每一列顯示：角色（👑 管理員／🎤 主播）、Google 帳號與暱稱、所屬廳房（下拉選單，選好即儲存；App 主播的廳房會直接寫回主播資料，與後台指派同步）
  • 已經用 App 登入過的主播會自動列出（標示 📱 App，角色為主播、廳房為後台指派的廳房），不用手動登記
  • 手動登記的帳號可指定角色與所屬廳房；若同一個帳號之後也用 App 登入，兩筆會合併成一列，角色與廳房以手動登記為準
  • 舊版 App 沒有記錄帳號的主播，會顯示「尚未記錄 Google 帳號」，該主播下次打開 App 就會自動補上

新增／移除

  1. 輸入 Google 帳號、選角色、選所屬廳房 →「新增」（同一個帳號不能重複登記）
  2. 每一列尾的 ✕ 都可以刪除，會連續確認兩次
  3. 刪除的是 📱 App 主播時，會連同該主播在雲端的全部資料一起清除（任務、分數、聽眾資料卡、設定），無法復原，效果與後台「收禮統計」的 🗑 刪除主播相同

廳房

  • 頁面下方「🏠 廳房」區塊列出所有廳房（預設的「未知」「野蠻女友」加上自訂廳房）
  • 輸入名稱按「＋ 新增廳房」即可新增；名稱不能包含「/」、不能以「_」開頭，也不能與既有廳房重複。目前尚未提供刪除廳房
  • 新廳房會立刻出現在此頁的「所屬廳房」下拉，後台重新整理後也會看到
目前這份名單只是「登記」，尚未套用任何權限限制——後台仍是通行密碼＋Google 登入。之後要依名單限制誰能進後台、誰能改哪個廳房的範本，再另行調整。
