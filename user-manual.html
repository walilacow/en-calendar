🎁 聲播日曆 使用者手冊 v1.4.3

聲播主專用：每日 / 每週 / 每月收禮目標追蹤、業績統計、聽眾管理、直播音效。建議用 Safari 開啟並「加入主畫面」，像 App 一樣使用。

〇、安裝到主畫面（iPhone Safari）

  1. 用 Safari 開啟你的網址
  2. 點底部的分享鈕 📤
  3. 選「加入主畫面」
  4. 按「新增」
桌面會出現聲播日曆圖示，點它直接開啟（全螢幕、沒有網址列）。打卡提醒與音效在這個模式下最穩定。
請用 Safari！Chrome 或其他瀏覽器的「加入主畫面」行為不同，容易拿到舊快取。

一、首頁・月曆總覽

  • 月曆格：綠框＝全部達成、橘字＝部分達成、紫框＝今天
  • 統計列：本月全達成 / 部分達成 / 本週任務 / 本月任務
  • 三個快捷鈕：搜尋趨勢、流行歌曲（找直播話題用）、音效庫
  • 聽眾資料卡：聽眾名單管理
  • 左右箭頭切月份，點日期開啟「日面板」

二、日面板：每天的核心工作區

每日 / 每週 / 每月 / 自訂 分頁

  • 新增任務：輸入名稱、個數、分數、選圖示 →「新增」
  • ✨簡＝5 分、🔥加＝100 分、普通＝10 分（固定）
  • +1 記一次完成；長按 +1 可直接輸入數量
  • 點任務名稱或 ✏️＝編輯該任務全部欄位
  • 週/月分頁可設該週、該月任務
🎯 業績目標：在每日/每週/每月分頁下方的「🎯 業績目標」輸入框直接設定（例如每日 300），改完自動存檔。

三、編輯任務

  1. 點任務名稱或 ✏️ 鉛筆
  2. 該任務＋上方表單一起紫色發光
  3. 修改任何欄位（含簡/加碼勾選）
  4. 按下方右側「💾 儲存」或「取消編輯」
完成進度（已收幾個）不會被編輯影響；改名成跟別人重複會被擋下。

四、禮拜六：一週收尾

  • 📻 當週時數：每滿 1 小時 +5 分（開播時段自動累計）
  • 📅 複製當週分數：一鍵產生本週明細文字（每日的 月/週/日/簡/加碼 分開列出＋時數＋總分），可直接貼給公會或存檔
  • 每日細項順序固定：月 → 週 → 日 → 簡 → 加碼
  • 📈 產生趨勢圖：本週業績＋任務兩張圖合併成一張大圖卡

五、禮物分界（直播日）

設定 → 業績 → 啟用禮物任務 → 每日分界。
設 08:00 時，「9/10」代表 9/10 08:00 ～ 9/11 08:00：凌晨打卡算 9/10、日曆「今天」在凌晨時亮在昨天、每週於禮拜日 08:00 起算。設 00:00 則與日曆日一致。

六、業績分界

業績分數（手動輸入的收禮分數）有獨立的「每日分界」：設 08:00 時，凌晨 0~8 點輸入的分數歸前一天統計。禮物分界與業績分界互不影響。

七、音效庫

  • 首頁「🔊 音效庫」→ 點按即播 16 種音效
  • 音量用 iPhone 實體音量鍵控制
iPhone 沒聲音？① 先隨便點一下畫面（解鎖 iOS 音訊）② 檢查側邊靜音開關 ③ 調大音量。

八、聽眾資料卡

  • 記錄常客：暱稱（必填）、ID、個性、生日、最近話題、截圖最多 2 張
  • 點卡片＝編輯；✕＝刪除（有確認）
  • 📤＝產生該聽眾的分享圖卡

九、分享圖卡

  • 聽眾卡 📤、日面板「📸 產生分享圖卡」、趨勢圖「📤 分享趨勢圖」都會開這個面板
  • 按「⬆️ 分享」→ 系統分享選單：儲存影像（存相簿）、Facebook、LINE、IG…

十、設定與雲端同步

  • 禮物/業績開關、每日分界、金龍城堡統計開關
  • 用 Google 登入：主播資料、任務、聽眾、業績全自動同步雲端，換手機或清資料，重新登入就全部回來
務必保持登入！沒登入的資料只存在本機，清 Safari 網站資料會全部消失。

十一、版本更新

  1. 我把新版本上傳後，你打開 App 會看到「🎉 發現新版本 vX.Y.Z，點此更新（資料不會遺失）」
  2. 點一下即完成更新，不需要刪圖示、清資料
  3. 沒看到提示？刪桌面圖示 → Safari 清除網站資料 → 重新加入主畫面（這招會清本機資料，登入者重新登入即可）
